# Positioning

## One-Line Positioning

AppFoundry helps AI-built apps become production-safe without forcing a backend migration.

## Longer Positioning

AI coding tools can scaffold working apps quickly, but generated apps often fail at production infrastructure details: feedback context, upload safety, debug log privacy, screenshot handling, object storage, and operational retention policies.

AppFoundry provides adapter-first building blocks and agent-readable recipes for those details.

## Audience

Primary:

- indie developers building with AI coding tools
- small teams shipping SwiftUI/web/mobile apps quickly
- developers with existing Express/Prisma/Postgres/S3-style backends
- privacy-conscious teams that want self-hostable feedback/debug infrastructure

Secondary:

- agencies and app studios maintaining many similar apps
- teams with legacy custom backends that do not want to migrate to a BaaS
- AI coding agents that need reliable implementation recipes

## Product Category

AppFoundry is not a BaaS, observability suite, uploader, auth framework, or analytics tool.

It is best described as:

- production rails for AI-built apps
- self-hostable feedback/debug infrastructure
- privacy-safe app diagnostics glue
- adapter-first app infrastructure toolkit

## What AppFoundry Should Be Remembered For

> Add feedback with annotated screenshots and safe debug logs to an existing app in minutes, without moving your backend.

## Competitive Framing

AppFoundry should not compete head-on with mature platforms.

Instead:

- use S3/R2/Supabase Storage through adapters
- integrate with Sentry/GlitchTip/PostHog/Highlight through adapters later
- learn from Uppy/tus for uploads instead of replacing them
- avoid becoming a full auth platform

## Product Principles

- Existing backend first.
- Privacy by default.
- Adapter over platform migration.
- Agent-readable over docs-heavy.
- Native app friendly.
- Narrow wedge before broad toolkit.
- Production guardrails over shiny demos.
